# 存储机制切换方案

> 日期：2026-06-21
> 项目：Memocast - 笔记应用存储机制双轨制

---

## 背景与目标

目前 Memocast 所有笔记数据存储在 `memocast.db`（sql.js SQLite）中，笔记内容以 Markdown 文本形式存在 `notes.content` 字段。本方案为笔记引入第二种存储机制：**本地 MD 文件**（即 `.md` 文件直接写入磁盘），支持用户在两种机制之间自由切换，并提供完整的数据备份与转换逻辑。

---

## 架构设计

### 两种存储机制

| 维度 | SQLite（当前） | 本地 MD 文件（新增） |
|------|-------------|------------------|
| 存储位置 | `{userData}/memocast.db` | `{userData}/notes/` 目录树 |
| 内容格式 | `content` 字段存 Markdown 文本 | 每篇笔记一个 `.md` 文件 |
| 分类映射 | `category` 字段（路径字符串） | 对应 `{category}/` 子目录结构 |
| 标签 | `note_tags` / `tags` 表 | Front-matter `tags:` 字段 |
| 元数据 | `data_created`, `data_modified` 等列 | Front-matter YAML 头 |
| 索引/搜索 | SQLite 全文索引 | 文件系统 + 内存索引 |
| 同步支持 | 现有 dirty 机制完全兼容 | 同左（MD 内容即同步内容） |

### 核心设计原则

1. **本地优先不变**：两种机制均为本地优先，云端（WizNote）仅作备份。
2. **数据模型统一**：数据库中仍保留 `notes` 表作为元数据索引和同步状态载体，只是 `content` 字段在 MD 模式下可为空（正文存在文件中）。
3. **静默切换**：切换存储机制后，新笔记自动使用新机制；旧笔记按需迁移或保持原机制存储。
4. **可逆切换**：用户可随时切回，迁移是增量且可中断的。
5. **主/渲染进程分离**：所有文件 I/O 在主进程执行，通过 IPC 暴露接口；渲染进程通过 `StorageService` 统一调用。
6. **最小侵入**：只在笔记内容读写路径上增加机制判断，不改动其他业务逻辑。
7. **降级保护**：MD 文件读取失败时自动降级到 DB content 字段；文件写入失败时保留 DB 内容。

### 目录结构（MD 模式）

```
{userData}/
└── notes/
    └── {category}/
        └── {title}.md
```

示例：

```
memocast/
├── notes/
│   ├── /                      ← 根目录
│   │   └── Untitled.md
│   ├── /工作/
│   │   ├── 项目A.md
│   │   └── 项目B.md
│   └── /工作/子目录/
│       └── 文档.md
```

## 数据模型变更

### notes 表新增字段

```sql
ALTER TABLE notes ADD COLUMN content_file TEXT;
ALTER TABLE notes ADD COLUMN storage_mechanism TEXT DEFAULT 'sqlite';
```

- `content_file`：MD 模式下指向文件路径，如 `/工作/项目A.md`
- `storage_mechanism`：标识该笔记所属存储机制（切换后新笔记用新机制，旧笔记保持原值）

### Front-matter 结构（MD 文件头）

每个 MD 文件头部包含 YAML front-matter：

```yaml
---
doc_guid: local_1234567890_abc123
kb_guid: ""
title: 项目A
category: /工作/
tags: [tag1, tag2]
data_created: 1717654321000
data_modified: 1717654321000
local_modified: 1717654321000
created_at: 1717654321000
updated_at: 1717654321000
dirty: 1
---
```

### 阶段 0：数据库字段预埋（与 Phase 1 并行）

在 `electron-main.js` 中为 `notes` 表新增两个字段，这是整个方案的数据基础。

**文件：** `src-electron/main-process/electron-main.js` 第 409 行附近

在现有迁移逻辑块中追加：

```javascript
// ========== 存储机制双轨制字段 ==========
if (!columns.includes('content_file')) {
  console.log('[DB] Migrating: adding content_file column')
  db.run("ALTER TABLE notes ADD COLUMN content_file TEXT")
  saveDatabase()
}

if (!columns.includes('storage_mechanism')) {
  console.log('[DB] Migrating: adding storage_mechanism column')
  db.run("ALTER TABLE notes ADD COLUMN storage_mechanism TEXT DEFAULT 'sqlite'")
  saveDatabase()
  console.log('[DB] ✅ storage_mechanism column added - dual storage enabled')
}
```

**字段语义：**

| 字段 | 类型 | 默认值 | 含义 |
|------|------|--------|------|
| `content_file` | TEXT | NULL | MD 模式下指向文件相对路径，如 `/工作/项目A.md`；SQLite 模式下为 NULL |
| `storage_mechanism` | TEXT | `'sqlite'` | 标识该笔记所属存储机制；切换后新笔记用新值，旧笔记保持原值 |

**为什么要用 `storage_mechanism` 而不是全局开关：**
- 切换机制后，旧笔记不会立即迁移，保持 `storage_mechanism='sqlite'`，内容仍从 DB 读取
- 新建/编辑时按当前机制写入，`storage_mechanism` 随之更新
- 支持未来"混合态"——部分笔记 MD、部分笔记 DB 并存

#### 1.3 新增 MD 文件存储适配器

**文件：** `src/lib/storage/MdFileAdapter.js`（新建）

这是最核心的新模块，需要处理文件 I/O、front-matter 序列化/反序列化、路径安全、文件名去重。

```javascript
import { ipcRenderer } from 'electron'
import path from 'path'
import fs from 'fs'
import yaml from 'js-yaml'

const invoke = (channel, payload) => ipcRenderer.invoke(channel, payload)

// notes 目录相对于 userData 的路径
const NOTES_DIR = 'notes'

// ============================================================
// 辅助函数
// ============================================================

/**
 * 将 category 路径转为合法目录名
 * "/"        → "_root_"
 * "/工作/"   → "_root_/工作/" (直接拼接)
 * "/工作/子/" → "_root_/工作/子/" (多层)
 */
function categoryToDir(category) {
  if (!category || category === '/' || category === '_root_/') {
    return NOTES_DIR
  }
  const rel = category.startsWith('/') ? category.slice(1) : category
  return path.join(NOTES_DIR, rel)
}

/**
 * 将 title 转为合法文件名
 * 处理非法字符：/ \ : * ? " < > |
 */
function sanitizeFilename(title) {
  if (!title || title.trim() === '') return 'Untitled'
  return title.replace(/[/\\:*?"<>|]/g, '_').trim()
}

/**
 * front-matter 序列化
 */
function serializeFrontMatter(note) {
  const meta = {
    doc_guid: note.doc_guid || '',
    kb_guid: note.kb_guid || '',
    title: note.title || 'Untitled',
    category: note.category || '/',
    tags: Array.isArray(note.tags) ? note.tags : (note.tags || '').split(',').filter(Boolean),
    data_created: note.data_created || note.dataCreated || null,
    data_modified: note.data_modified || note.dataModified || null,
    local_modified: note.local_modified || null,
    created_at: note.created_at || null,
    updated_at: note.updated_at || null,
    dirty: note.dirty !== undefined ? note.dirty : 1
  }
  const yamlStr = yaml.dump(meta, { flowLevel: 0, lineWidth: -1 })
  return `---\n${yamlStr}---\n`
}

/**
 * front-matter 反序列化
 * @param {string} rawContent - 原始 MD 内容（含 front-matter）
 * @returns {{ meta: Object, content: string }}
 */
function deserializeFrontMatter(rawContent) {
  const match = rawContent.match(/^---\r?\n([\s\S]*?)\r?\n---\r?\n?([\s\S]*)$/)
  if (!match) {
    return { meta: {}, content: rawContent }
  }
  try {
    const meta = yaml.load(match[1]) || {}
    const content = match[2]
    return { meta, content }
  } catch (e) {
    console.warn('[MdFileAdapter] Failed to parse front-matter:', e.message)
    return { meta: {}, content: rawContent }
  }
}

// ============================================================
// 主类
// ============================================================

class MdFileAdapter {
  /**
   * 将笔记写入 MD 文件
   * @param {Object} note - 笔记对象
   * @param {string} userDataPath - Electron userData 路径
   */
  async saveNote(note, userDataPath) {
    if (!userDataPath) {
      userDataPath = await invoke('storage:getUserDataPath')
    }

    const dir = categoryToDir(note.category || '/')
    const dirPath = path.join(userDataPath, dir)
    const fileName = sanitizeFilename(note.title || 'Untitled')
    let filePath = path.join(dirPath, fileName + '.md')

    // 文件名冲突处理：加序号后缀
    if (fs.existsSync(filePath)) {
      let counter = 1
      let exists = true
      while (exists) {
        const candidate = path.join(dirPath, `${fileName} (${counter}).md`)
        exists = fs.existsSync(candidate)
        if (!exists) {
          filePath = candidate
          break
        }
        counter++
      }
    }

    // 确保目录存在
    if (!fs.existsSync(dirPath)) {
      fs.mkdirSync(dirPath, { recursive: true })
    }

    // 写入文件：front-matter + 正文
    const frontMatter = serializeFrontMatter(note)
    const content = note.content || ''
    fs.writeFileSync(filePath, frontMatter + content, 'utf8')

    // 返回文件相对路径（相对于 userData，用于存入 DB 的 content_file）
    return path.relative(userDataPath, filePath).replace(/\\/g, '/')
  }

  /**
   * 从文件读取笔记内容
   * @param {string} contentFile - content_file 字段值（相对路径）
   * @param {string} userDataPath
   */
  async readNoteContent(contentFile, userDataPath) {
    if (!userDataPath) {
      userDataPath = await invoke('storage:getUserDataPath')
    }
    const filePath = path.join(userDataPath, contentFile)
    if (!fs.existsSync(filePath)) {
      console.warn(`[MdFileAdapter] File not found: ${filePath}`)
      return null
    }
    const rawContent = fs.readFileSync(filePath, 'utf8')
    const { content } = deserializeFrontMatter(rawContent)
    return content
  }

  /**
   * 将 MD 文件转换为笔记对象（仅含元数据，不含正文内容）
   */
  async fileToNoteMeta(filePath, userDataPath) {
    const rawContent = fs.readFileSync(filePath, 'utf8')
    const { meta } = deserializeFrontMatter(rawContent)

    return {
      doc_guid: meta.doc_guid || '',
      kb_guid: meta.kb_guid || '',
      title: meta.title || path.basename(filePath, '.md'),
      category: meta.category || '/',
      tags: Array.isArray(meta.tags) ? meta.tags.join(',') : (meta.tags || ''),
      data_created: meta.data_created || null,
      data_modified: meta.data_modified || null,
      local_modified: meta.local_modified || null,
      content_file: path.relative(userDataPath, filePath).replace(/\\/g, '/'),
      storage_mechanism: 'md-files',
      dirty: meta.dirty
    }
  }

  /**
   * 遍历 notes/ 目录获取所有 MD 文件的元数据
   */
  async listFiles(options = {}, userDataPath) {
    if (!userDataPath) {
      userDataPath = await invoke('storage:getUserDataPath')
    }
    const notesDir = path.join(userDataPath, NOTES_DIR)
    const results = []

    if (!fs.existsSync(notesDir)) return results

    const walk = (dir) => {
      const entries = fs.readdirSync(dir, { withFileTypes: true })
      for (const entry of entries) {
        const fullPath = path.join(dir, entry.name)
        if (entry.isDirectory()) {
          walk(fullPath)
        } else if (entry.isFile() && entry.name.endsWith('.md')) {
          try {
            const note = this.fileToNoteMeta(fullPath, userDataPath)
            results.push(note)
          } catch (e) {
            console.warn(`[MdFileAdapter] Failed to parse: ${fullPath}`, e.message)
          }
        }
      }
    }

    walk(notesDir)
    return results
  }

  /**
   * 删除 MD 文件
   */
  async deleteFile(docGuid, userDataPath) {
    if (!userDataPath) {
      userDataPath = await invoke('storage:getUserDataPath')
    }
    // 需要先查询 content_file
    const note = await invoke('db:getNoteByDocGuid', docGuid)
    if (!note || !note.content_file) return false

    const filePath = path.join(userDataPath, note.content_file)
    if (fs.existsSync(filePath)) {
      fs.unlinkSync(filePath)
    }
    return true
  }

  /**
   * 计算 MD 文件模式下的磁盘占用（人类可读）
   */
  async getDiskUsage(userDataPath) {
    if (!userDataPath) {
      userDataPath = await invoke('storage:getUserDataPath')
    }
    const notesDir = path.join(userDataPath, NOTES_DIR)
    let totalSize = 0

    if (fs.existsSync(notesDir)) {
      const walk = (dir) => {
        const entries = fs.readdirSync(dir, { withFileTypes: true })
        for (const entry of entries) {
          const fullPath = path.join(dir, entry.name)
          if (entry.isDirectory()) {
            walk(fullPath)
          } else if (entry.isFile()) {
            totalSize += fs.statSync(fullPath).size
          }
        }
      }
      walk(notesDir)
    }

    // 人类可读格式化
    const formatSize = (bytes) => {
      if (bytes < 1024) return `${bytes} B`
      if (bytes < 1024 * 1024) return `${(bytes / 1024).toFixed(1)} KB`
      return `${(bytes / (1024 * 1024)).toFixed(1)} MB`
    }

    return { bytes: totalSize, formatted: formatSize(totalSize) }
  }
}

export default new MdFileAdapter()
```

**关键实现细节说明：**

1. **路径安全**：`sanitizeFilename` 处理 `/ \ : * ? " < > |` 等非法字符；`categoryToDir` 确保根目录笔记写入 `notes/_root_/` 而非与分类混淆
2. **文件名冲突**：用 ` (1)`, ` (2)` 序号后缀解决，不丢数据
3. **front-matter 解析**：使用 `js-yaml` 库，兼容有/无 `---` 分隔符的 MD 文件；解析失败时静默降级，将全文当作 content
4. **content_file 相对路径**：存储相对于 userData 的路径，便于跨设备迁移
5. **userDataPath 获取**：通过 IPC `storage:getUserDataPath` 获取主进程的 userData 路径（渲染进程无法直接访问 `app.getPath('userData')`）


#### 2.1 迁移引擎核心

```javascript
import path from 'path'
import fs from 'fs'
import yaml from 'js-yaml'

// 主进程专用工具（通过 ipcMain.handle 注册后，ipcRenderer.invoke 调用）
// 以下代码标注 [Main] 表示在主进程执行，通过 IPC 暴露

// ============================================================
// 备份模块
// ============================================================

const MAX_BACKUP_COUNT = 3

function getBackupDir(basePath, type) {
  return path.join(basePath, `.backup_${type}`)
}

function listBackups(backupDir) {
  if (!fs.existsSync(backupDir)) return []
  return fs.readdirSync(backupDir)
    .filter(f => f.startsWith('backup.'))
    .sort()
    .reverse()
}

function cleanupOldBackups(backupDir) {
  const backups = listBackups(backupDir)
  backups.slice(MAX_BACKUP_COUNT).forEach(f => {
    const full = path.join(backupDir, f)
    if (fs.statSync(full).isDirectory()) {
      fs.rmSync(full, { recursive: true })
    } else {
      fs.unlinkSync(full)
    }
  })
}

/**
 * 备份 memocast.db → .backup_sqlite/memocast.db.backup.{timestamp}
 */
async function backupSqliteDb(userDataPath) {
  const src = path.join(userDataPath, 'memocast.db')
  if (!fs.existsSync(src)) return null

  const backupDir = getBackupDir(userDataPath, 'sqlite')
  if (!fs.existsSync(backupDir)) {
    fs.mkdirSync(backupDir, { recursive: true })
  }

  cleanupOldBackups(backupDir)

  const timestamp = Date.now()
  const dest = path.join(backupDir, `memocast.db.backup.${timestamp}`)
  fs.copyFileSync(src, dest)
  console.log(`[Migration] SQLite DB backed up to: ${dest}`)
  return dest
}

/**
 * 备份 notes/ → .backup_mdfiles/notes.backup.{timestamp}/
 */
async function backupMdFiles(userDataPath) {
  const src = path.join(userDataPath, 'notes')
  if (!fs.existsSync(src)) return null

  const backupDir = getBackupDir(userDataPath, 'mdfiles')
  if (!fs.existsSync(backupDir)) {
    fs.mkdirSync(backupDir, { recursive: true })
  }

  cleanupOldBackups(backupDir)

  const timestamp = Date.now()
  const dest = path.join(backupDir, `notes.backup.${timestamp}`)
  copyDirRecursive(src, dest)
  console.log(`[Migration] MD files backed up to: ${dest}`)
  return dest
}

function copyDirRecursive(src, dest) {
  if (!fs.existsSync(src)) return
  fs.mkdirSync(dest, { recursive: true })
  const entries = fs.readdirSync(src, { withFileTypes: true })
  for (const entry of entries) {
    const srcPath = path.join(src, entry.name)
    const destPath = path.join(dest, entry.name)
    if (entry.isDirectory()) {
      copyDirRecursive(srcPath, destPath)
    } else {
      fs.copyFileSync(srcPath, destPath)
    }
  }
}

// ============================================================
// 辅助函数
// ============================================================

function categoryToDir(category) {
  if (!category || category === '/' || category === '_root_/') {
    return 'notes'
  }
  const rel = category.startsWith('/') ? category.slice(1) : category
  return path.join('notes', rel)
}

function sanitizeFilename(title) {
  if (!title || title.trim() === '') return 'Untitled'
  return title.replace(/[/\\:*?"<>|]/g, '_').trim()
}

function serializeFrontMatter(note) {
  const meta = {
    doc_guid: note.doc_guid || note.docGuid || '',
    kb_guid: note.kb_guid || note.kbGuid || '',
    title: note.title || 'Untitled',
    category: note.category || '/',
    tags: Array.isArray(note.tags) ? note.tags :
      (note.tags || '').split(',').filter(Boolean),
    data_created: note.data_created || note.dataCreated || null,
    data_modified: note.data_modified || note.dataModified || null,
    local_modified: note.local_modified || null,
    dirty: note.dirty !== undefined ? note.dirty : 1
  }
  const yamlStr = yaml.dump(meta, { flowLevel: 0, lineWidth: -1 })
  return `---\n${yamlStr}---\n`
}

function deserializeFrontMatter(rawContent) {
  const match = rawContent.match(/^---\r?\n([\s\S]*?)\r?\n---\r?\n?([\s\S]*)$/)
  if (!match) return { meta: {}, content: rawContent }
  try {
    return { meta: yaml.load(match[1]) || {}, content: match[2] }
  } catch (e) {
    return { meta: {}, content: rawContent }
  }
}

// ============================================================
// 导出：SQLite → MD 文件
// ============================================================

const BATCH_SIZE = 50

async function exportToMdFiles(db, saveDatabase, userDataPath, onProgress) {
  const notesDir = path.join(userDataPath, 'notes')
  if (!fs.existsSync(notesDir)) {
    fs.mkdirSync(notesDir, { recursive: true })
  }

  const allNotes = db.exec('SELECT * FROM notes ORDER BY id')
  if (!allNotes.length) return { exported: 0, failed: 0, errors: [] }

  const rows = allNotes[0].values
  const cols = allNotes[0].columns
  const total = rows.length
  let exported = 0
  let failed = 0
  const errors = []

  for (let i = 0; i < rows.length; i += BATCH_SIZE) {
    const batch = rows.slice(i, i + BATCH_SIZE)
    for (const row of batch) {
      const note = {}
      cols.forEach((col, idx) => { note[col] = row[idx] })

      try {
        const dir = categoryToDir(note.category || '/')
        const dirPath = path.join(userDataPath, dir)
        const fileName = sanitizeFilename(note.title || 'Untitled')
        let filePath = path.join(dirPath, `${fileName}.md`)

        // 冲突处理
        if (fs.existsSync(filePath)) {
          let counter = 1
          while (fs.existsSync(filePath)) {
            filePath = path.join(dirPath, `${fileName} (${counter}).md`)
            counter++
          }
        }

        if (!fs.existsSync(dirPath)) {
          fs.mkdirSync(dirPath, { recursive: true })
        }

        const frontMatter = serializeFrontMatter(note)
        const content = note.content || ''
        fs.writeFileSync(filePath, frontMatter + content, 'utf8')

        const contentFile = path.relative(userDataPath, filePath).replace(/\\/g, '/')

        // 回写 DB：更新 content_file 和 storage_mechanism
        db.run(
          'UPDATE notes SET content_file = ?, storage_mechanism = ? WHERE id = ?',
          [contentFile, 'md-files', note.id]
        )

        exported++
      } catch (err) {
        failed++
        errors.push({ id: note.id, title: note.title, error: err.message })
        console.error(`[Migration] Export failed: id=${note.id}`, err.message)
      }
    }

    saveDatabase()

    if (onProgress) {
      onProgress({
        current: Math.min(i + BATCH_SIZE, total),
        total,
        phase: 'exporting'
      })
    }
  }

  return { exported, failed, errors }
}

// ============================================================
// 导入：MD 文件 → SQLite
// ============================================================

async function importFromMdFiles(db, saveDatabase, userDataPath, onProgress) {
  const notesDir = path.join(userDataPath, 'notes')
  if (!fs.existsSync(notesDir)) return { imported: 0, failed: 0, skipped: 0, errors: [] }

  const allFiles = []
  const walk = (dir) => {
    const entries = fs.readdirSync(dir, { withFileTypes: true })
    for (const entry of entries) {
      const fullPath = path.join(dir, entry.name)
      if (entry.isDirectory()) walk(fullPath)
      else if (entry.isFile() && entry.name.endsWith('.md')) allFiles.push(fullPath)
    }
  }
  walk(notesDir)

  const total = allFiles.length
  let imported = 0
  let failed = 0
  let skipped = 0
  const errors = []

  for (let i = 0; i < allFiles.length; i++) {
    const filePath = allFiles[i]
    const relPath = path.relative(userDataPath, filePath).replace(/\\/g, '/')

    try {
      const rawContent = fs.readFileSync(filePath, 'utf8')
      const { meta, content } = deserializeFrontMatter(rawContent)

      const docGuid = meta.doc_guid || `local_${Date.now()}_${Math.random().toString(36).substring(2, 10)}`

      // 检查是否已存在（通过 doc_guid）
      const existing = db.exec(
        'SELECT id FROM notes WHERE doc_guid = ?', [docGuid]
      )
      if (existing.length && existing[0].values.length > 0) {
        // 已存在，更新内容
        const noteId = existing[0].values[0][0]
        db.run(`
          UPDATE notes
          SET content = ?, title = ?, category = ?, tags = ?,
              data_modified = ?, local_modified = ?, storage_mechanism = ?,
              content_file = NULL, dirty = 1
          WHERE id = ?
        `, [
          content,
          meta.title || path.basename(filePath, '.md'),
          meta.category || '/',
          Array.isArray(meta.tags) ? meta.tags.join(',') : (meta.tags || ''),
          meta.data_modified || Date.now(),
          meta.local_modified || Date.now(),
          'sqlite',
          noteId
        ])
        skipped++
      } else {
        // 插入新记录
        const now = Date.now()
        db.run(`
          INSERT INTO notes
          (doc_guid, kb_guid, title, content, category, tags,
           data_created, data_modified, local_modified, created_at, updated_at, dirty,
           storage_mechanism, content_file)
          VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, NULL)
        `, [
          docGuid,
          meta.kb_guid || '',
          meta.title || path.basename(filePath, '.md'),
          content,
          meta.category || '/',
          Array.isArray(meta.tags) ? meta.tags.join(',') : (meta.tags || ''),
          meta.data_created || now,
          meta.data_modified || now,
          meta.local_modified || now,
          now, now, 1,
          'sqlite'
        ])
        imported++
      }
    } catch (err) {
      failed++
      errors.push({ file: relPath, error: err.message })
      console.error(`[Migration] Import failed: ${relPath}`, err.message)
    }

    if (i % 50 === 0 && onProgress) {
      onProgress({ current: i + 1, total, phase: 'importing' })
    }
  }

  saveDatabase()
  return { imported, failed, skipped, errors }
}

// ============================================================
// 导出接口（注册为 IPC 处理器）
// ============================================================

// 在 electron-main.js 中通过以下方式使用：
// ipcMain.handle('migration:start', async (event, { direction, userDataPath, db }) => { ... })

// direction: 'sqlite-to-md' | 'md-to-sqlite'
// 返回：{ success, summary, errors, backupPath }
async function runMigration(direction, userDataPath, db, saveDatabase) {
  const state = {
    direction,
    phase: direction === 'sqlite-to-md' ? 'exporting' : 'importing',
    progress: { current: 0, total: 0 },
    errors: [],
    lastError: null,
    startedAt: Date.now()
  }

  try {
    // Step 1: 备份
    if (direction === 'sqlite-to-md') {
      await backupSqliteDb(userDataPath)
    } else {
      await backupMdFiles(userDataPath)
    }

    // Step 2: 执行迁移
    const onProgress = (p) => {
      state.progress = p
      // 同步到 app_state（渲染进程可轮询）
      try {
        db.run(`INSERT OR REPLACE INTO app_state (key, value, updated_at)
                VALUES ('storage.migration', ?, ?)`, [JSON.stringify(state), Date.now()])
        saveDatabase()
      } catch (e) { /* ignore */ }
    }

    let result
    if (direction === 'sqlite-to-md') {
      result = await exportToMdFiles(db, saveDatabase, userDataPath, onProgress)
    } else {
      result = await importFromMdFiles(db, saveDatabase, userDataPath, onProgress)
    }

    // Step 3: 更新机制配置
    const newMechanism = direction === 'sqlite-to-md' ? 'md-files' : 'sqlite'
    db.run(`INSERT OR REPLACE INTO app_state (key, value, updated_at)
            VALUES ('storage.mechanism', ?, ?)`, [newMechanism, Date.now()])
    saveDatabase()

    state.phase = 'completed'
    state.progress = { current: state.progress.total, total: state.progress.total }
    state.summary = result

    return { success: true, ...state }

  } catch (err) {
    state.phase = 'failed'
    state.lastError = err.message
    console.error('[Migration] FAILED:', err)

    // 尝试回滚：删除刚导出的 MD 文件（或恢复 DB 备份）
    try {
      if (direction === 'sqlite-to-md') {
        const notesDir = path.join(userDataPath, 'notes')
        if (fs.existsSync(notesDir)) {
          fs.rmSync(notesDir, { recursive: true })
        }
      }
    } catch (rollbackErr) {
      console.error('[Migration] Rollback failed:', rollbackErr.message)
    }

    return { success: false, ...state }
  }
}
```

#### 2.4 备份策略详解

| 切换方向 | 备份时机 | 备份内容 | 备份位置 |
|---------|---------|---------|---------|
| SQLite → MD | 导出前 | `memocast.db` 完整副本 | `{userData}/.backup_sqlite/memocast.db.backup.{timestamp}` |

**备份保留规则：** 最多保留 3 份，超出后删除最旧的（按时间戳排序）。

```javascript
  const userDataPath = app.getPath('userData')
  const notesDir = path.join(userDataPath, 'notes')
  let totalSize = 0
  const walk = (dir) => {
    if (!fs.existsSync(dir)) return
    const entries = fs.readdirSync(dir, { withFileTypes: true })
    for (const entry of entries) {
      const fullPath = path.join(dir, entry.name)
      if (entry.isDirectory()) walk(fullPath)
      else totalSize += fs.statSync(fullPath).size
    }
  }
  walk(notesDir)
  const format = (b) => b < 1024 * 1024 ? `${(b / 1024).toFixed(1)} KB` : `${(b / (1024 * 1024)).toFixed(1)} MB`
  return { bytes: totalSize, formatted: format(totalSize) }
```

```javascript
export async function loadLocalWorkspaceData() {
  await DatabaseClient.categories.ensureOfflineRoot()

  // SQLite 笔记（所有笔记都在 DB 中，content_file 字段区分存储机制）
  const sqliteNotes = await DatabaseClient.notes.getAll()

  // 【存储机制双轨制】如果启用了 MD 文件模式，补充 content_file 字段已存在的 MD 笔记元数据
  const mechanism = await DatabaseClient.appState.get('storage.mechanism')
  let mdFilesMeta = []

  if (mechanism === 'md-files') {
    try {
      mdFilesMeta = await ipcRenderer.invoke('storage:listMdNoteFiles')
    } catch (e) {
      console.warn('[loadLocalWorkspaceData] Failed to list MD files:', e.message)
    }
  }

  // 合并：sqliteNotes（含 storage_mechanism=md-files 且有 content_file 的记录）+ 纯 MD 元数据
  // 同一 doc_guid 的笔记只保留一条（SQLite 记录优先，因为包含完整字段）
  const mergedNotes = deduplicateNotesByDocGuid([...sqliteNotes, ...mdFilesMeta])

  const tree = buildCategoryTreeFromNotes(mergedNotes, categories)

  return {
    notes: mergedNotes,
    categories,
    tree
  }

/**
 * 按 doc_guid 去重，SQLite 记录优先（因为字段更完整）
 */
function deduplicateNotesByDocGuid(notes) {
  const map = new Map()
  for (const note of notes) {
    if (!note.doc_guid) continue
    if (!map.has(note.doc_guid)) {
      map.set(note.doc_guid, note)
    }
  }
  return Array.from(map.values())
}
```

```javascript
function registerStorageHandlers() {
  const userDataPath = app.getPath('userData')

  // 读取 MD 文件内容
  ipcMain.handle('storage:readMdNoteContent', async (event, contentFile) => {
    const filePath = path.join(userDataPath, contentFile)
    if (!fs.existsSync(filePath)) return null
    try {
      const raw = fs.readFileSync(filePath, 'utf8')
      const match = raw.match(/^---\r?\n[\s\S]*?\r?\n---\r?\n?([\s\S]*)$/)
      return match ? match[1] : raw
    } catch (e) {
      console.error('[Storage] Read MD failed:', e.message)
      return null
    }
  })

  // 保存笔记为 MD 文件
  ipcMain.handle('storage:saveMdNote', async (event, note) => {
    // 调用 MigrationEngine 的 write 函数（抽取为独立函数）
    const { writeMdNote } = require('./lib/storage/migration-helpers')
    return await writeMdNote(note, userDataPath)
  })

  // 删除 MD 文件
  ipcMain.handle('storage:deleteMdNoteFile', async (event, contentFile) => {
    const filePath = path.join(userDataPath, contentFile)
    if (fs.existsSync(filePath)) {
      fs.unlinkSync(filePath)
    }
    return true
  })

  // 列出所有 MD 文件元数据
  ipcMain.handle('storage:listMdNoteFiles', async () => {
    const { listMdNoteFiles } = require('./lib/storage/migration-helpers')
    return await listMdNoteFiles(userDataPath)
  })
}
```

## 风险与注意事项

1. **文件名冲突**：同目录下标题相同的笔记需要去重，可加序号后缀（`项目A.md`, `项目A (1).md`）
2. **分类路径安全**：将 `/` 转为合法目录名，如 `工作` → `_root_工作` 或直接用 `_` 表示根目录
3. **内容编码**：MD 文件统一使用 UTF-8，解析时需处理 BOM
4. **迁移原子性**：备份 → 迁移 → 验证 → 切换，分步执行，失败可回滚
5. **性能**：MD 文件模式下，笔记列表加载需遍历文件系统，建议内存缓存
6. **WizNote 同步**：同步层不感知存储机制变更，仍按现有 dirty 机制工作
