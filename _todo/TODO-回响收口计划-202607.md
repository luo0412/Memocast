# 回响/符文 4 项收口实施计划（深度版）

## 决策锚点（已与用户确认）

- 「深」路径：4 项 都不是单纯重命名/补齐，而是 真正 重新打语义。

## 收口 2：`createDefaultEchoAnnoSource` 双轨重构

### 当前签名（EchoRuntime.js）

```javascript
export const createDefaultEchoAnnoSource = (echoName = '回响') => `export default {
  kind: 'echo',
  version: 1,
  name: '${name}',
  render (context = {}) {
    const attrs = context.attrs || {}
    const prompt = context.prompt || ''
    ...
    return { type: 'card', icon, color, title, description, prompt, attrs, html: attrs.html || '' }
  }
}`
```

→ 仅 `render(context)` 一种输出：决定卡片外观（icon/color/title/description/prompt/attrs/html）。

### 目标签名（双轨）

**轨 A（旧，保留兼容性）**：`render(context) → card`

**轨 B（新，TODO 提议 + 默认模板采用）**：

```javascript
export const createDefaultEchoAnnoSource = (echoName = '回响') => `export default {
  kind: 'echo',
  version: 1,
  name: '${name}',
  namespace: '回响',

  render (node, ancestors) {
    // node: token = { type:'echo_anno', echoName, echoId, attrsParsed, prompt, raw, range, ... }
    // ancestors: 包含 从 document → block → paragraph 的父节点链
    const attrs = node?.attrsParsed || {}
    const prompt = node?.prompt || ''
    return {
      type: 'card',
      icon: attrs.icon || ancestors?.echo?.icon || '${DEFAULT_ECHO_ICON}',
      color: attrs.color || ancestors?.echo?.color || '${DEFAULT_ECHO_COLOR}',
      title: attrs.title || ancestors?.echo?.name || '${name}',
      description: attrs.desc || ancestors?.echo?.desc || '',
      prompt,
      attrs,
      html: attrs.html || ''
    }
  },

  afterRender (node, domElement, ancestors) {
    // domElement 已 插入到 DOM，可 访问 nextElementSibling / classList / dataset
    // 默认 实现 不动 周围节点，仅 给宿主 加一个 class 以便用户 直观看到「这个 echo 是什么」
    if (domElement) domElement.classList.add('ag-echo-default-mounted')
  }
}`
```

### 关键改动

1. **EchoRuntime.js**：
   - `compileDefinition` 增加 新分支：若 `definition.render` 是 **双参 `(node, ancestors)`**，按轨 B 调用；否则 仍按 旧 `render(context)` 调用。
   - `extractRuneMeta` 已经是 `definition.attrs.kind === 'rune'`，无需变。
   - 新增 `__isRenderB = (definition.render && definition.render.length === 2)` 启发式判断。

2. **EchoFormDialog.vue**：
   - 「重置模板」按钮 现在 调的就是 `createDefaultEchoAnnoSource`，它已经是新模板签名，OK。
   - watch `form.name` 里的 字符串替换 仍可用。
   - 内置回响（isBuiltin）下 Monaco 是 readOnly，无需动。

3. **11 个内置回响**：每个 `anno_source` 里 `render(context)` 的实现 暂不动（运行时通过函数参数长度自动判 轨 A/B）；但 nice 那一例 改成 新签名 以做演示。

## 收口 3：lucky 真接 AI 校对

### 现状

`@强运{action:'ai-proofread', model:'gpt-4o-mini'}()` 点击后 handler 调 `window.__memocastRuneHandlers.lucky({runeNode, meta, scopeContainer})`，但 全局回调 未注册。

### 改造目标

1. **新增 service**：`src/services/AiProofreadService.js`
   - `proofread(markdown, { model, signal, onToken }) → { corrected: string, diff: [{op, text}] }`
   - 默认 调 `PortkeyService.chat(messages, { model })`，messages 构造：
     - system: 「你是 markdown 校对助手，返回仅校对后 markdown，不要解释」
     - user: 当前 markdown
   - 失败 时 降级：抛 `Promise.reject(new Error(...))`，由 调用方 notify。

2. **Header.vue 注册全局回调**：
   ```javascript
   mounted () {
     this.__memocastRuneHandlers = {
       lucky: this.handleLuckyTrigger.bind(this)
     }
     window.__memocastRuneHandlers = Object.assign(
       window.__memocastRuneHandlers || {},
       this.__memocastRuneHandlers
     )
   }
   beforeDestroy () {
     if (window.__memocastRuneHandlers) {
       delete window.__memocastRuneHandlers.lucky
     }
   }
   ```

3. **handleLuckyTrigger** 流程：
   - 从 `this.$store.state.server.currentNote` + 打开的编辑器实例（通过 $root / ref / vuex）拿 markdown。
   - 如果 无 默认 AI 配置 → `$q.notify` 提示「请在设置中配置 AI provider」。
   - 调用 `AiProofreadService.proofread(markdown, { model })`。
   - 渲染结果 处理：在 lucky 容器 上加 `ag-rune-lucky-result` class + 浮层提示「AI 已校对（n 字差异，点击插入替换）」。
   - 点击 浮层 → `updateNote(corrected)` 覆盖 当前 笔记。

4. **i18n**：`aiLuckyNoConfig: '请在设置中配置 AI provider'`, `aiLuckyProofreading: 'AI 正在校对…'`, `aiLuckyResult: 'AI 校对完成：n 处差异'`。

## 收口 4：替罪 / 招灾 赋予合理语义

### 替罪（scapegoat）—— 「接住后续 rune 错误」

语义：把 scapegoat 插在某段末尾，后续 rune 若 因 DOM 异常 / attr 缺失 等报错，错误 不会 在容器 paint 失败，而是在 scapegoat 容器上 累积「受伤」 class + 文案：

```javascript
handler (runeNode, container, meta) {
  const block = runeNode.closest('[data-block-type], .mu-block, p, pre, li, h1, h2, h3, h4, h5, h6, blockquote') || runeNode.parentElement
  if (!block) return () => {}
  // 1) 把 scapegoat 容器自身 标成「救场位」
  block.classList.add('ag-rune-scapegoat-standby')
  // 2) 注册 window 上的全局 error catcher
  const onError = (event) => {
    block.classList.add('ag-rune-scapegoat-injured')
    block.setAttribute('data-scapegoat-error', event.message || 'unknown')
  }
  window.addEventListener('error', onError, true)
  // 3) 收集 未来 rune handler 抛错（监听 runtime 自定义事件）
  const onRuneError = (event) => {
    if (!event?.detail) return
    block.classList.add('ag-rune-scapegoat-injured')
    block.setAttribute('data-scapegoat-rune-error', String(event.detail.runeId || ''))
  }
  window.addEventListener('ag:rune:error', onRuneError)

  return () => {
    window.removeEventListener('error', onError, true)
    window.removeEventListener('ag:rune:error', onRuneError)
    block.classList.remove('ag-rune-scapegoat-standby', 'ag-rune-scapegoat-injured')
    block.removeAttribute('data-scapegoat-error')
    block.removeAttribute('data-scapegoat-rune-error')
  }
}
```

### 招灾（calamity）—— 「随机哥德」

语义：在 scope='siblings' 内 随机选 30% 的可见文字节点，临时 给它们 加 `ag-rune-calamity-gothic` class（CSS 实现 哥特体 / 染彩），3 秒后 自动清除；如果 同一段落有 第二 个 calamity，比例 +20%（最多 80%）：

```javascript
handler (runeNode, _container, meta) {
  const container = resolveScopeContainer(runeNode, 'siblings')
  if (!container) return () => {}
  // 找出所有 text 节点
  const targets = collectTextNodes(container).filter(n => n.textContent.trim().length > 1)
  const ratio = Math.min(0.8, 0.3 + (meta?.attrs?.intensity ? Number(meta.attrs.intensity) * 0.1 : 0))
  const picked = pickRandom(targets, Math.floor(targets.length * ratio))
  picked.forEach(n => {
    n.parentElement && n.parentElement.classList.add('ag-rune-calamity-gothic')
  })
  return () => {
    picked.forEach(n => {
      n.parentElement && n.parentElement.classList.remove('ag-rune-calamity-gothic')
    })
  }
}
```

CSS：

```css
.ag-rune-calamity-gothic {
  font-family: 'UnifrakturMaguntia', 'Old English Text MT', serif;
  background: linear-gradient(120deg, #ff1744, #f50057, #d500f9, #651fff);
  background-clip: text;
  -webkit-background-clip: text;
  color: transparent;
  text-shadow: 0 0 4px rgba(255, 23, 68, 0.4);
}
```
